# Portfolio-3D 🚀👨‍💻

A sleek, interactive 3D developer portfolio built with modern technologies. This project is designed to showcase personal projects, skills, and creativity with smooth navigation and rich visuals using Three.js.

🌐 **Live Demo:** [Click to Visit](https://davidraj1510.github.io/Portfolio-3D/)

---

## 🎯 Features

- 🌐 Single-page application with smooth client-side routing
- 🧭 Navigation using **React Router**
- 🧩 Component-driven architecture using **React + TypeScript**
- ⚡ Blazing fast development with **Vite**
- 🎨 Custom-styled components using **Tailwind CSS**
- 🖼️ 3D visuals powered by **Three.js**
- 🧠 Efficient data/state management via **TanStack**
- 💡 Clean, minimalist icons from **Lucide React**
- 📱 Fully responsive design for all screen sizes
- 🚀 Deployed on **GitHub Pages**

---

## 🔧 Tech Stack

| Tech               | Role                                      |
|--------------------|-------------------------------------------|
| **React**          | Core UI framework                         |
| **TypeScript**     | Static typing for scalable code           |
| **Vite**           | Super-fast build tool                     |
| **Three.js**       | 3D rendering engine                       |
| **Tailwind CSS**   | Utility-first CSS framework               |
| **React Router DOM** | Navigation and route handling           |
| **Lucide React**   | Icon library for React                   |
| **TanStack**       | Data fetching and advanced routing (if used) |
